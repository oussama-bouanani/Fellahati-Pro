# تقرير الاختبارات

تاريخ التقرير: 2026-10-18

## آلي

- حساب تحويل طن إلى kg.
- مجموع الحصاد والمبيعات والمصاريف.
- حساب المخزون والربح.
- تجاهل السجلات المحذوفة من الإحصائيات.
- قواعد Firestore: سماح للمالك، منع مستخدم آخر، رفض بيانات غير صالحة (يتطلب Emulator).

## تحقق من البنية والنشر

- نجح `pnpm test`: ‏3/3 اختبارات حسابية.
- نجح بناء الإنتاج بـ Vite.
- نجح تجميع ونشر قواعد Firestore والفهارس.
- أُنشئت قاعدة Firestore Standard في `europe-west1` مع حماية الحذف.
- نُشرت PWA على `https://fellahati-pro-bouanani-2026.web.app`.
- فُعّل تسجيل الدخول بالبريد وكلمة المرور.
- نجح إنشاء ومزامنة مشروعي Capacitor Android وiOS بالإصدار 7.6.9.

## تحقق يدوي متبقٍ

- Google Sign-In والبريد/كلمة السر وإعادة التعيين.
- إنشاء حسابين والتأكد من عزل البيانات.
- جهازان بالحساب نفسه: مزامنة وتنزيل السجلات.
- وضع الطيران، إغلاق/فتح التطبيق، ثم إعادة الشبكة والمزامنة.
- التثبيت من Chrome Android وSafari iPhone.
- بناء واختبار AAB على Android متوقف إلى حين تثبيت Android Studio/JDK وإعداد مفتاح التوقيع.
- بناء واختبار IPA متوقف إلى حين توفر macOS وXcode وتوقيع Apple Developer.

لا تُعتبر البنود المتبقية ناجحة حتى تُنفذ بحسابات اختبار وأجهزة حقيقية. اختبار قواعد Firestore عبر Emulator متوقف محلياً لعدم توفر Java.
